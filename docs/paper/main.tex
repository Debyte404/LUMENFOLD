% --- CGF Journal, submission version.
%
% The class's \JournalSubmission stamp prints "submitted to COMPUTER GRAPHICS
% Forum (<month>/<year>)." Two problems with using it as-is: it asserts a
% submission that has not happened, and the date is \number\month/\number\year,
% i.e. the COMPILE date, so the line silently changes every time the paper is
% rebuilt and two builds of identical source disagree about when it is from.
%
% The statement below is deliberately one that is true before submission and stays
% true after it: it names the venue the paper is prepared for and fixes the date.
% When the paper is actually submitted, change "manuscript prepared for" to
% "submitted to" here and nothing else needs touching.

% Paragraphs are run-in headings, not numbered sections. The class numbers them by
% default and its \paragraph counter carries an unused subsubsection level, so every
% one of them rendered as "4.1.0.1", "7.8.0.1" -- a visible defect in a journal
% submission. Stopping numbering at the subsection level leaves them as the bold
% run-in heads they are meant to be.
\setcounter{secnumdepth}{2}


% ---------------------------------------------------------------------------
% Float placement.
%
% Every float in this paper was declared [t] -- top of page only. Three of the
% full-width figures (9, 10, 11) were queued all the way to the back of the
% document as a result, leaving pages 25, 27 and 28 with 551 pt, 396 pt and
% 233 pt of blank space respectively. Measured, not guessed: tools/paper_qa.py
% reports the blank bands and the page each float lands on.
%
% Two changes. Double-column floats (figure*/table*) accept only [t] and [p] in
% LaTeX, so [t] -> [tp] is the whole of the available freedom there. And the
% fraction limits below are LaTeX's defaults, which are conservative for a paper
% with this many wide figures: raising topfraction lets a page hold one big float
% plus text instead of pushing the float on, and floatpagefraction stops a float
% page being rejected for being "too full" and cascading.
% ---------------------------------------------------------------------------
\renewcommand{\topfraction}{0.92}
\renewcommand{\bottomfraction}{0.5}
\renewcommand{\textfraction}{0.06}
\renewcommand{\floatpagefraction}{0.7}
\renewcommand{\dbltopfraction}{0.92}
\renewcommand{\dblfloatpagefraction}{0.7}

% A run-in \paragraph followed by a float should not be split across pages.
