# Any-Mesh Any-Light Injector Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Caustic Injector bake any closed static mesh under sun/point/spot/area lights with color and absorption, then animate it.

**Architecture:** New `tools/mesh_caustic/` package (tracer + band correction, numpy-only, no scipy) consumed by a new mesh Bake operator in the addon; solver-scene path untouched. Phase 2 adds per-frame bake and image-sequence injection, gated on Phase 1 green.

**Tech Stack:** Blender 5.x Python (bpy, numpy, no scipy), existing addon patterns, Steam 5.2 headless tests.

**Spec:** `docs/superpowers/specs/2026-11-01-addon-anymesh-design.md`

## Global Constraints

- One change per commit; EVIDENCE before paper before summaries.
- `Solver scene` mode byte-identical: same flags, same output, existing tests unchanged.
- Airy scale stays the documented visibility parameter, never physical.
- Absolute paths only; Blender 5.x; Steam 5.2 headless tests.
- No paper text edits in this work.
- Explicitly unsupported in v1, refused by name: rough/transmission-rough glass, volumetrics inside the body, nested dielectrics, motion blur.

## Review Focus

- Open mesh silently baking half a caustic; a reasonable person gets a named refusal before any bake starts — pinned in Task 4 with an open-cube test that must CANCEL with "not watertight".
- Receiver without usable UVs mapping the field to the wrong place; person gets a named refusal — pinned in Task 4 with a no-UV plane test.
- Point light placed inside the glass body producing NaNs; person gets a refusal or clamped light — pinned in Task 2 with an inside-light test.
- 300^2 bake on a 200k-tri mesh taking an hour; person sees a time estimate before committing — pinned in Task 5 with an estimate-accuracy test.
- Animated topology change (fluid remesh) silently десyncing frames; person gets a refusal when vertex count changes — pinned in Task 7 with a remesh test.
